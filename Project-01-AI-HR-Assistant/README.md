# 项目一：AI+HR 员工制度问答助手（个人项目）

> **项目类型**：个人独立项目（AI Native 产品探索）
> **完成时间**：2026.3
> **我的角色**：产品经理（负责需求调研、Prompt设计、知识库搭建、测试与迭代）
> **核心工具**：Coze / Dify / RAG (检索增强生成)

---

## 🎯 1. 项目背景与痛点
在传统企业内部，HR政策查询存在明显痛点：
- **信息分散且繁琐**：员工手册、薪酬福利、报销规范等文档冗长，员工寻找特定信息耗时较长。
- **重复性咨询高**：HR团队每天需要花费大量精力回答“年假怎么算”、“报销标准是什么”等基础问题，效率低下。
- **传统搜索体验差**：关键词搜索往往无法精准匹配员工口语化的提问，导致答非所问。

**项目目标**：构建一个基于私有知识库的AI问答助手，实现精准的、口语化的HR政策查询，提升员工体验并释放HR人力。

---

## 👥 2. 目标用户与核心场景
- **核心用户**：企业全体员工（120+人试点）。
- **核心场景**：
  - 员工在报销前，快速查询差旅住宿标准。
  - 新员工入职时，咨询年假、社保缴纳等福利政策。
  - HR在解答员工问题时，使用该助手作为辅助验证工具。

---

## 🧠 3. AI 产品架构与核心逻辑
本项目采用 `Agent (意图识别) + RAG (知识库) + LLM` 的架构。

[用户提问] 
   ↓
[Agent 意图识别]  → 闲聊/非HR问题 → [兜底回复策略]
   ↓ (识别为政策查询)
[向量化检索 (RAG)] → 匹配私有知识库(员工手册/薪酬福利)
   ↓
[LLM 生成回答] → 严格基于知识库内容输出 → [返回用户]

---
##🛠️ 4. 核心工作拆解（对应简历）
4.1 需求梳理与方案设计
调研并拆解了员工最常咨询的Top 20问题。

梳理了“提问-识别-检索-生成-反馈”的全链路功能逻辑。

4.2 Prompt 设计与角色边界
为了确保AI回答的专业性和安全性，我设计了系统级Prompt。
Prompt 设计核心（节选）：

"你是一位专业、亲和的企业HR助手。你的任务是基于提供的知识库文档，准确回答员工关于薪酬、福利、考勤等政策的问题。
约束条件：

严禁编造知识库中不存在的政策。

如果知识库无法回答，必须回答：‘抱歉，该问题我暂时无法解答，建议您联系HR部门XXX。’

语气要保持耐心、客观，避免产生法律风险。"

4.3 知识库搭建与数据清洗（RAG）
上传并清洗了模拟的员工手册、薪酬福利政策文档（约0.8万字）。

优化了文档切分（Chunk）的颗粒度，确保检索片段有完整的上下文语义，提升了召回准确率。

4.4 兜底回复策略与意图识别分支
为防止AI产生幻觉（Hallucination）或答非所问，我配置了意图识别分支：

意图识别：将用户提问分类为“政策查询”、“闲聊”、“系统操作”、“投诉建议”。

兜底策略：当置信度低于阈值（如0.7），或提问属于非HR领域时，触发兜底回复，引导用户转接人工HR。
